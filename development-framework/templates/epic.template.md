# `EPIC-NNNN` — short title

| Field | Value |
|---|---|
| **ID** | `EPIC-NNNN` |
| **Status** | proposed / committed / in-progress / done / abandoned |
| **Opened** | YYYY-MM-DD |
| **Section(s)** | `SECTION` code(s) this epic spans |
| **Sponsor / owner** | who's accountable |

## Goal

The outcome, in business/user terms. An epic is a large body of work
broken into stories; it is not itself directly implementable.

## Business value

Why this matters, and to whom.

## Scope

What's in, what's explicitly out.

## Child stories

| Story | Title | Status |
|---|---|---|
| `STORY-NNNN` | … | … |

An epic with zero stories is still in grooming, not committed.

## Definition of done

Checkable against child stories all being done, not a separate checklist.
