# `BEHAVIOR` — Behavioural invariants

**Document:** rules/framework/fw-framework-rules.md
**Defined:** 2026-08-23
**Parent:** none
**Sub-domains:** none

Rules in this domain do not supersede, amend, or contradict any rule in
another domain unless explicitly stated below against that rule's ID.

## Scope

How an agent operating on catalyst must act, independent of the deployed
tree's own shape: how it refers to catalyst, when it installs, what it
calls itself, and when it's allowed to push. These are not machine-checkable
from a tree snapshot — they govern conduct during a session, not artifacts
left behind by one.

None.
