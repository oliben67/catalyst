# Catalyst prompts

Choose the prompt file that matches the agent you are running, and load only that file.

- Use `CLAUDE.md` when running Claude Code.
- Use `AGENT.md` when running a generic agent workflow.
- Use `SYSTEM.md` when running the system-level prompt.

All three load `BOOTSTRAP.md`, the single portable install core.

Open the selected file and follow its instructions from top to bottom.
